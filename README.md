# Supermarket Retail Sales & Customer Performance Analysis

## Project Overview
This project analyzes supermarket retail sales data to evaluate business performance, understand customer purchasing behavior, and identify sales trends.

The project uses SQL Server for data storage and analysis, and Power BI to create an interactive dashboard.

## Tools & Technologies
- SQL Server
- SQL
- Power BI
- DAX

## Database Structure
The database consists of four related tables:

- **Customers:** Customer information, including name, city, and age.
- **Products:** Product details, categories, prices, and costs.
- **Orders:** Order dates, customer IDs, and order statuses.
- **OrderDetails:** Products included in each order, quantities, and discounts.

## SQL Analysis
SQL was used to:
- Retrieve and filter data.
- Combine tables using JOINs.
- Apply aggregate functions.
- Group data to analyze sales performance.
- Calculate total revenue and profit.
- Analyze monthly sales trends.
- Examine customer purchasing behavior.
- Use subqueries for additional analysis.

## Power BI Dashboard
An interactive dashboard was developed to present key business metrics and sales performance.

The dashboard includes:
- Total Revenue
- Total Profit
- Total Customers
- Total Orders
- Total Quantity Sold
- Revenue by Category
- Revenue by City
- Revenue by Product
- Sales Trends Over Time
